# ansi51_blockchain
This repository contains the research results from the Laboratory of Alternative Energies and Electrical System Protection, conducted by Eng. Luiz A. Tarralo Passatuto [user: tarralo] under the guidance of Phd. Wellington Maycon S. Bernardes [user: wmsb].
O conteúdo aqui presente é fruto do trabalho da Dissertação de Mestrado de Luiz A. Tarralo Passatuto, e seu uso é livre para fins diversos, desde que seja mencionado o trabalho original e seus autores.
O leitor poderá encontrar aqui os scripts em Python para otimização dos parâmetros de relés de sobrecorrente para três sistemas testes da IEEE, o 13 barras, o 34 barras e o 37 barras. 
Também estão presentes as modelagens para o OpenDSS destes sistemas e os resultados obtidos através da metodologia proposta. 
O aplicativo desenvolvido via streamlit permite ao leitor interagir com os arquivos aqui contidos através de uma estrutura Blockchain, que serve como uma ferramenta didática ao funcionamento desta tecnologia inovadora. 
Demais informações podem ser encontradas no trabalho original.
